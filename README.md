# Параллельный поиск подстроки (naive_threads)

Программа на языке C, реализующая наивный алгоритм поиска всех вхождений шаблона в строке с использованием многопоточности (библиотека `pthread`). 

Множество позиций-кандидатов делится на равные непересекающиеся диапазоны, каждый из которых обрабатывается отдельным потоком. Результаты синхронизируются с помощью мьютекса для корректного вывода.

## Требования для сборки
* Компилятор `gcc` (или `clang`).
* ОС семейства Linux / macOS / WSL (так как используется POSIX API, в частности `pthread` и `getopt`).

## Компиляция

Для сборки программы выполните следующую команду в терминале:

```bash
gcc -Wall -Wextra -pthread naive_threads.c -o naive_threads
```

#№ Запуск программы

Синтаксис командной строки:

```bash
./naive_threads [-t <количество_потоков>] <путь_к_файлу>
```
-t <число> - необязательный аргумент. По умолчанию количество потоков будет равно число ядер процессора.
<путь к файлу> - обязательный аргумент
